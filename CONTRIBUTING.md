# Contributing

Contributions are welcome, and beyond a trivial fix they start with an issue rather than
a pull request: agree on the problem and the approach in an issue first, then implement.
The process, the pull-request expectations and the design-record rules are on the
documentation site at
[Contributing](https://flink-gcp.github.io/flink-connector-gcp/docs/development/contributing/),
and [Development](https://flink-gcp.github.io/flink-connector-gcp/docs/development/) next to it
covers the toolchain, the build and the test suites.

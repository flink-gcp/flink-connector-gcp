# Cases PubSubRecoveryReport.java and its Python port in tools/tier3 must decide
# alike. A case names its records per subscription for the run "oracle",
# accepts output messages in order as "accept <output message ID> <payload>",
# and ends with one result: the counters the complete report returns
# ("expect"), the message of the first refusal ("reject"), or "refuse" where
# the JDK writes that message and only the refusal is shared. Both test suites
# read this file and require its case count.
